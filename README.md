# Travel Insurance Backend
Backend API for the Travel Insurance application.

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- SQLite
- Maven

## Prerequisites
- JAVA JDK 17 or later is required
- Git
- Intellij or other IDE
- Maven

## Setup
1. Clone the backend repository
```
git clone https://github.com/Kitpro001/travelinsurance.git
```

2. Run the project. 
```
mvn spring-boot:run
```

3. The application will run on:
```
http://localhost:8081
```

4. Continue to setup frontend application by referring to the link below:
```
https://github.com/Kitpro001/travelinsurance-fe
```
